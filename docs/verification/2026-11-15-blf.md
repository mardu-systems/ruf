# Account-scoped SIP BLF — 15 November 2026

Local observations for the issue #14 working-tree implementation based on
`cbd3336`. These results do not qualify a future hosted release or a Windows
runtime. Fixtures use synthetic accounts, generated private test trust and an
isolated loopback Asterisk container.

## Implementation

Existing account-save, credential, native queue and snapshot/event paths now carry
BLF configuration/status. libre/baresip 4.13 subscriptions own signaling and
lifetimes; a bounded Rust XML reducer handles RFC 4235 full/partial coherence.
The existing settings draft manages targets and the dialer displays a standalone
account-scoped list. No new service, IPC command, SDK patch or audio pipeline.
`quick-xml` 0.42 was already locked and is now a direct adapter dependency.
See [the complete contract](../api/blf.md).

The BLF wire fixtures verify Digest credentials, full/partial updates, malformed

renewal evidence, retired subscriptions, independent accounts, outbound proxy
routing, TCP and verified TLS. Asterisk verified real idle → ringing → busy → idle,

checks include 32 targets with long names at 320×440 and actual hit-testing of the
last target and active-call hangup control.

Review found two issues fixed with observed failing/passing regressions: response
`Retry-After` was not honored, and removed accounts retained dialog tables.

## Initial-run observation and limits

The first full native runner failed only
`sip_event_tests::retired_register_timeout_preserves_replacement_registration`:
a single snapshot after 33 seconds was `Registering`, not `Registered`. Two exact
isolated repetitions passed (33.08/33.09 seconds), then the final complete native
runner passed all partitions. Temporary instrumentation was
removed. Existing network recovery can initiate registration again, and this
fixture discards the current UDP reply source; the original failure has no packet
trace sufficient to establish the cause. No speculative production fix was made.

Commands used `PATH=/opt/homebrew/opt/rustup/bin:$PATH` for the pinned Rust 1.98.1:
the default Homebrew compiler initially failed on a missing Z3 dylib. The SDK
build used `OPENSSL_ROOT_DIR=$PWD/native/build/openssl-macos14/install` because
the default Homebrew OpenSSL requires macOS 27. No global installation/settings
were changed. Local app signing was ad hoc; notarization was skipped.

Windows runtime, physical headset behavior, arbitrary providers and real host
interface changes were not qualified by these checks. Network invalidation was
covered by the existing native recovery harness and subscription recovery by
real loopback signaling. The live UI screenshots use synthetic IPC fixtures.
